# PRODUCT

## 产品是什么

一个只在本机运行的 Windows 多 Agent 桌面宠物。它把 OpenCode、Claude Code、Pi、Hermes 的工作状态、提问、完成、失败和权限请求汇总到同一个可视入口，并把生硬的工具参数解释成人能快速判断的中文。

## 用户真正要完成的事

- 离开终端时，一眼知道哪个 Agent 在干什么、是否需要自己回来处理。
- 权限请求出现时，看懂“哪个窗口、正在做什么、为什么需要、会影响哪里”。
- 同时开多个 Agent 时，能按 Agent、项目、会话、工具、路径或关键词找到指定事件。
- 连接断了时，软件明确说出断在哪，而不是静默没反应。

## 第一版边界

- Windows 11，本机单用户。
- OpenCode 做第一条真实接入；其余三家保留适配接口与模拟验证。
- 不做 SSH、手机端、云同步、远程审批、自动更新。
- 普通状态只通知；权限默认回原 Agent 窗口处理。
- 默认不把提示词、代码、日志或密钥发到网络。

## 成功标准

- 桌宠重启后，下一条 Agent 事件自动重新连上。
- 普通通知失败不阻塞 Agent。
- 乱序和重复事件不会把完成状态倒退成工作状态。
- 中文关键词能从任务摘要、原因、工具和路径中搜到对应事件。
- 用户不需要看日志就能判断连接是否健康。
