# Agent 看板

看板命令（下面简写成 `看板`）：
```
node "E:\个人AI资源管理\10_按项目存放（某个项目专用的脚本和资料）\01_手作园（自己从0搓的·应用网页工具）\应用\多Agent桌面宠物（统一通知与权限说明）\app（Electron本体·带git）\scripts\bookmark-cli.mjs"
```

## 读条目（每种活都从这一步起）

号码全板统一：各组 → 交接单专区 → 待定一路往下编，一个号只有一条，不用管在哪组。

- 他贴来「看板第 N 条（某组）的单独文件：路径」→ 只读那个文件
- 他点了号码 → 直接 `看板 show 7`（`7-9`、`7,9,12`、`捆2` 也行），不先 list；顺嘴带了组名照样只写号码
- 没点号码、问有啥活 → `看板 list --to <组名>`（交接单专区 `list --handoff`）只看标题，挑出相关的再 show
- show 第一行 `━━ 第 N 条 · 组名 组 · id …`，第二行标题——标题对不上他说的事就停下问他（号码跟着拖动会变）；图跟这次的活有关才打开

**算做完**：读进来的只有点名那几条（或那个文件、或一份标题清单），标题对得上。`list --json` 是整组原文，只给程序用。

## 接下来按活找一份（都在本夹）

| 碰到什么 | 读哪份 |
|---|---|
| 他口头叫你接看板上某条、接别家派来的 | `领活.md` |
| 窗口快满、换窗口接着干、交出去；接一张交接单 | `交接单.md` |
| 把写死的活拆给便宜 AI、一键启动、审交回来的报告 | `派活单.md` |
| 分捆、工兵按捆一条条领、调度收件箱 | `看板派工.md` |
| 命令全表、记一条（`add`）、派给别家 | 仓库根 `AGENT_INTEGRATION.md`；`看板 --help` |

命令报「看板没开」→ 自己把桌宠开起来，等十秒重试，不用问他（开法在 `交接单.md` 一、⑤）。
