# Agent 看板

**一句话**：先看目录再翻页。`看板 list` 只出号码和小标题；`看板 show <组名> <号码>` 只读点名那几条的全文。他点了哪几条，就只读那几条。

看板命令（下面都简写成 `看板`）：
```
node "E:\个人AI资源管理\10_按项目存放（某个项目专用的脚本和资料）\01_手作园（自己从0搓的·应用网页工具）\应用\多Agent桌面宠物（统一通知与权限说明）\app（Electron本体·带git）\scripts\bookmark-cli.mjs"
```

## 一、读看板（每次都这么读）

- [ ] ① **他点了号码 → 直接 show，不先 list**。号码就是他屏幕上条目左边那个数、捆标题上的「捆N」：
  - 「Claude 第 7 条」→ `看板 show Claude 7`；「7 到 9」→ `7-9`；「7、9、12」→ `7,9,12`；「捆2」→ `看板 show Claude 捆2`
  - 「交接单第 2 条」→ `看板 show 交接单 2`；待定区 → `看板 show 待定 3`
  - 他没说组名 → 用你自己那组：Claude Code＝`Claude`，Codex＝`ChatGPT`，Pi＝`Pi Agent`，还有 `Antigravity`、`Hermes`
- [ ] ② **他没点号码、要你看看有啥活** → `看板 list --to <组名>`（交接单用 `list --handoff`），扫标题挑出相关的，再 show 那几条
- [ ] ③ **核对标题**：show 每条第一行是 `━━ 组名 号码 · id …`，下一行是标题。标题对不上他说的那件事，就停下问他——号码跟着他拖动、新加条目会变
- [ ] ④ **图按需打开**：show 只给图片路径和标注清单，跟这次的活有关才用读图工具打开

- ❌ 他说「看 Claude 第 7 条」→ `看板 list --to Claude --json`，整组 4 万字读完再找第 7 条
- ✅ → `看板 show Claude 7`，只读这一条

**算做完**：读进来的只有他点名那几条的全文，或者一份标题清单；标题跟他说的事对得上。

`list --json` 一吐就是整组原文，只给程序处理全量数据用。

## 二、按活翻子文件

| 碰到什么 | 读哪份 |
|---|---|
| 交接单（写、接）；换个窗口接着干；窗口快满了 | 同夹 `交接单.md` |
| 多人派工：分捆分工、工兵按捆一条一条领、调度审核 | 同夹 `看板派工.md` |
| 用 `next` 领了一条活以后怎么干、日常档和睡觉档 | 不用翻：`next` 领到时吐出来的那段就是规矩，照它走 |
| 记一条、派给别家（`add --to`）、命令全表 | 仓库根 `AGENT_INTEGRATION.md`；`看板 --help` |

## 三、坑

- **看板没开**：命令报「看板没开」→ 自己把桌宠开起来，等十秒重试，不用问他。开法在 `交接单.md` 第一节⑤
- **他说完工了才删**：他说「好了／可以／完工了」，这条就由你删——用 `next` 领的走 `看板 done <id> --by 窗口名 --ok "他的原话"`；没领、直接 show 读的走 `看板 remove <id>`。id 在 show 那一行的 `id …` 里。他没说，就留着
- **组名写开头也认**：`Pi` 认得出 `Pi Agent`；`交接单专区`、`待定区` 也认
