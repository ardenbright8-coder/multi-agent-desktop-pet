# Agent 看板（接活必读总流程）

看板命令（下面简写成 `看板`）：
```
node "F:\程序\0016_多Agent桌面宠物\scripts\bookmark-cli.mjs"
```

本技能只住在看板目录里，不常驻挂进各家 Agent；凡是从看板 **💭 待定**、**🤖 Agent 分组（含交接单专区）**、**📁 项目** 三处接到活的 AI，进门先读本份再动手。号码全板统一（各组 → 交接单专区 → 待定一路往下编），一个号只有一条。

## 一、给多少读多少（拖拽、点号码、右键复制、`Ctrl+C` 同一个规矩）

- **待定 / Agent 分组的单子**：拖一条、点号码复制、或悬停按 `Ctrl+C` 给你的 `条目（一条一份）\<id>.md`，**只读这一份**，别翻整组；拖一捆或 `Ctrl+C` 一捆给你几份，就只读那几份。
- **📁 项目页的文档与文件夹**：
  - 拖或复制（右键「复制给 AI」或悬停 `Ctrl+C`）某一个小按钮（如 `设计思路`、`执行过程`、`第2步派活`）→ **只读给你的那一份**（它开头点名要读的同夹文件照「项目夹」路径读，别的用到再开；一份派活稿有 2-A、2-B 多张时只干点名那张）。
  - 拖或复制**整个项目文件夹**（如整行「中医」「库管理面板」）→ 才把那个项目夹里的文档全看一遍。
  - 只口头说了项目名（「库管第 2 步派活」）：项目夹都在 `F:\应用数据\AgentPetHub\bookmark\projects\<项目名>\`，列这一层对一下（不在搜索范围，别去搜）。
  - 🚨 **写思路与执行过程的死规矩**：`设计思路.md`、`执行过程.md` 及各类方案稿，**只准写用户已拍板敲定的方案与真实执行记录；还在商量、设想、草案阶段的内容一律不准写入**。

## 二、接单到自动销单的完整流程（待定 · Agent 分组 · 交接单）

1. **认单标在干**：还没标你窗口名的，先敲 `看板 next <号或id> --by <窗口名>` 接下（窗口名取「家名-活的俗名」，别跟开着的窗口重名；拖入或复制后已被看板自动标成你窗口名在干的，不用重敲）。
   - 他明说「只看看、不接」才不标；原文对不上他说的事 → 照吐回来的 `release` 放回再问他。
   - 报「X 在干」领不到 → 问他那个窗口关没关，关了就 `看板 release <id> --by X` 再 `next`（原窗口 1 小时没动静的，`next` 时程序自动接过来）。
2. **大小单分流（原话锁死不改）**：
   - **多步单 / 老交接单**：由你这个干活的 AI 亲手拆成「大项 `- [ ] 1` + 缩进两格小项 `- [ ] 1.1`」两层结构化打勾清单（**不交给便宜小模型或子 agent**，最后一项固定留给「向用户汇报并经审核确认交单」），先在对话里给用户看简述版，**等他点头后**运行 `看板 清单 <id> --file <清单.md> --by <窗口名>` 挂进看板。看板自动把原话锁进 `<id>（原话）.md` 不动，在看板窗口显示可点小方框、在聊天框底下同步亮起红绿圆点。
   - **随手一句话小单**：本来就不值得拆好几步的小事，免拆打勾清单，按干活规矩跟用户确认后直接做。
3. **边干边勾（前后端同步）**：挂了清单的单子，每完成一步马上敲 `看板 勾 <id> <项号> --by <窗口名>`（勾错再敲一次取消；小项全勾完大项自动变绿；改了东西漏勾停手会被钩子提醒；用户在看板点小方框也能勾，`Ctrl+Z` 撤回）。卡住的项不勾，跳过接着干别的。
4. **汇报审核与自动销单**：做完向用户汇报审核，**等用户亲口说可以 / 没问题后**：
   - **有清单的单子**：敲 `看板 勾 <id> <最后一项>` —— **全勾完那一刻，看板自动把这张单子（连同 `--closes` 管着的旧单）一起销掉**，记进 `做完记录（最近50条·看板自动写）.md`，聊天框底下的圆点当场收起，不用再敲 `done`（若这单提交改过 `src/bookmark` 代码，收单前须先写好书签维修夹或设计夹说明）。
   - **免拆清单的一句话小单**：敲 `看板 done <id> --by <窗口名> --ok "<他的原话>"` 自动销单收起。
5. **中途换窗口 / 先不做挂起**：
   - 挂了打勾清单的单子本身就是现成交接单，换窗口**不另写新交接单**：先敲 `看板 log <id> --by <窗口名> --text "停在哪、下一步"`，再敲 `看板 release <id> --by <窗口名>` 放回，下一个窗口 `next` 接着勾同一份清单。
   - 他说这张先不做、以后再说 → `看板 挂起 <号> --why "他原话"`（沉到专区最底下；以后点名 `next` 自动取消挂起）。

## 三、只看不接

- 点了号码 → `看板 show 7`（`7-9`、`7,9,12`、`捆2` 也行），不先 `list`；图片跟这次活有关才打开。
- 没点号码、说了件事（「看板里语音那条」）→ 有 `kb-search-board` 工具先搜一句，只读命中的那份单独文件；没有就 `看板 list --to <组名>`（交接单专区 `list --handoff`）只看标题，挑出相关的再 `show`。
- `remove` 只在他点名删时用；`list --json` 是一整组原文，只给程序用。命令报「看板没开」→ 照 `交接单.md` 一、⑤ 自己把桌宠开起来等十秒重试。
