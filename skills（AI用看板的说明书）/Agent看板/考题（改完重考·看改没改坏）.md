# 考题

**目录**：怎么考 · 读看板 · 交接单 · 看板派工

## 怎么考

1. 开一个新会话（不带这次的聊天记录），只说题目原话。批量考用：
   `claude -p "<原话>" --permission-mode plan --model <平时干活的模型> --output-format stream-json --verbose --no-session-persistence < /dev/null > 题N_第M遍.jsonl`
2. 每道跑 1 遍，没过的改完再补跑 1 遍。开考前先告诉他要开几个 AI，他点头再跑
3. 对照「应该做到」逐条打钩，全勾上才算过；看它读了哪几份、按什么顺序
4. 结果记到各节末尾「历次结果」
5. 也可以用便宜模型开 Pi 窗口考（他 2026-10-13 定：弱模型能干好，强的就肯定行）：`pi --model commandcode/z-ai/glm-5.3-flash --thinking max --skill <Agent看板夹> --name 看板考试-N "<题目>"`。🚨 题目带空格时别直接当命令行参数拆着传，先写进文件再整句读出来传，不然 Pi 只收到第一段（2026-10-13 1 号窗口只收到「你看一下」）

## 读看板（SKILL.md 第一节）

### 题R1 · 点号码
原话：「你看一下看板 Claude 第 7 条和第 9 条」
应该做到：
- [ ] 开了 Agent看板 skill
- [ ] 直接 `show Claude 7,9`（或分两次 show），没跑 `list --json`、没先 list 整组
- [ ] 回话前核对了标题

### 题R2 · 点捆、没说组名
原话：「把捆2 那几件事看看，先说说你打算怎么弄」
应该做到：
- [ ] 用自己那组（Claude Code 就是 `show Claude 捆2`）
- [ ] 只读这一捆，不读别的捆

### 题R3 · 问还有啥活
原话：「看板上我这边还有啥没干完的？」
应该做到：
- [ ] `list --to Claude` 只看标题，挑出相关的再 show，没读全组原文

### 读看板历次结果

- 2026-10-13：Pi 开 5 个窗口考（GLM 5.3 flash、思考档 max、只挂本 skill，一窗一题，他看过前两窗结果说「其他功能我都测了没问题」）。5 窗都先读 SKILL.md，再按号码 `show`，没有一窗跑 `list --json`、没读别的条：
  - 「Claude 第 3、5 条」→ `show Claude 3`、`show Claude 5`，标题对上、只读不改
  - 「Claude 第 2、7、10 条」→ `show Claude 2,7,10`

  - 「交接单里苹果互传那张」→ `list --handoff` 看标题 → `show 交接单 1`，按交接单.md 说了接手第一步、没删（题2 的「接」只考到读，没让它真删）

## 交接单（交接单.md）

### 题1 · 写（他只说一个词）
原话：「交接单」
应该做到：
- [ ] 先开了 Agent看板 skill，读了 `交接单.md`
- [ ] 判断出是「写」（当前窗口有活），写六块、六块齐全
- [ ] 先给他看一眼再写进看板；默认不带 `--to`，落交接单专区
- [ ] 没有建议他压缩

### 题2 · 接
原话：「接看板里的交接单」
应该做到：
- [ ] 先开了 Agent看板 skill，读了 `交接单.md`
- [ ] 用 `list --handoff` 看标题、`show 交接单 <号>` 读详情，没用 `--json` 读全量、没凭标题干活

- [ ] 用 `next` 标成「在干」，没 `remove`（2026-10-14 他纠正：接了就删，他看不到谁在干）
- [ ] 干完先问要不要完工，他说完工才 `done --ok "他的原话"`

### 题3 · 他没点名「交接单」

## 看板派工（看板派工.md）

### 题1：手动选两捆
原话：「ctrl键……一二三条……四五六条……单独给它做起来」
应该做到：选同组1、2、3，生成第一捆后清掉选择；再选4、5、6生成另一捆；只调整捆归属，不覆盖原文。

### 题2：调度自动分工
原话：「agent你派活的过程中，你来自己分块……哪一块是谁干的」
应该做到：调度理解原始需求，整理成有目标、范围、步骤、测试的工单，再生成几捆；不把整段聊天塞给工兵，不自行开工兵窗口。

### 题3：另一个窗口不能抢同捆
原话：「这一块已经有Agent在干了……拉另外一块」
应该做到：整捆锁定；通过另一个条目编号领取也被拒绝；另一个工兵只能选同调度范围内另一捆。

### 题4：做完一条接下一条
原话：「第一条干完……待审核……第二条」
应该做到：自测后保存报告、退出待做队列、不删除原任务；原窗口仍占整捆，自动领取本捆下一条；调度审核并修小问题，用户最终测试。

### 擦边题：普通单人活
原话：「帮我查这一个文件哪里写错了，不用派工」
应该做到：直接处理普通任务，不创建派工捆，不启用多人协同，不开模型窗口。

### 看板派工历次结果

- 2026-10-07：按用户真实场景作人工逐条核对；程序锁捆与界面操作另有隔离回归。未额外启动AI考试，不把人工核对冒充模型实测。
