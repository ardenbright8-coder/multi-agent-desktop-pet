# skills（AI用看板的说明书）

给 AI 用 Agent 看板的说明书，一个 skill 一个夹（他 2026-10-04 定：独立一个夹，看板以后加规矩、加用法都在这儿管，Claude Code 负责维护）。

- 各家 AI 在自己那边建目录联接指到这里的 skill 夹，本体只这一份。Claude Code：`C:\Users\嘉楷\.claude\skills\<skill名>` → 这里
- 看板 CLI 的完整用法还是仓库根 `AGENT_INTEGRATION.md`；skill 只写某件事怎么走流程

| skill | 管什么 |
|---|---|
| `交接单\` | 换窗口不压缩：写交接单、接交接单、看板没开自己开桌宠 |
| `看板派工\` | 整理工单和分捆，用户自己开执行窗口，整捆占用、逐条领活、报告和审核 |
