# 交接单（Agent 看板）

**一句话**：换窗口不压缩，靠看板上的一张交接单接上。写的窗口把没干完的写成六块交给 Claude，接的窗口读完先问没拍板的、干完自己删。

看板命令（下面都简写成 `看板`）：
```
node "E:\个人AI资源管理\10_按项目存放（某个项目专用的脚本和资料）\01_手作园（自己从0搓的·应用网页工具）\应用\多Agent桌面宠物（统一通知与权限说明）\app（Electron本体·带git）\scripts\bookmark-cli.mjs"
```
用法全表：`看板 --help`；看板别的功能和规矩：同仓库根 `AGENT_INTEGRATION.md`。

## 一、写交接单（这个窗口要收尾）

- [ ] ① **聊定了还没落文件的决定，先写进它该在的文件**（项目 `AGENTS.md`、skill、说明文档），交接单里只写「已写进哪」。交接单会被删，长期要用的东西不能只活在交接单里
- [ ] ② **写六块**，先存成会话临时夹里的 md。开头一行：日期时间 · 哪摊活 · 他最后怎么定的。没有的那块写「无」，别删块：
  - **项目**：在哪个夹、现在是哪一版、接手先开哪个 skill 先读哪份
  - **我欠他的**：说过要做还没做的，一条一件，写到下一步具体做什么
  - **等他回答的**：他还没拍板的选择。接手先问，不替他选
  - **做了一半的**：改了没测、没提交的文件；全提交了写「无（最后一次提交 xxx）」
  - **接手要开、要关的**：要加载的 skill；开着的临时服务、后台程序
  - **试过不行的路**：踩过的坑、走不通的办法，一句一条，带图号或文件名
- [ ] ③ **给他看一眼**：六块各一两行贴给他，他要补就补进去（他 2026-10-02：不用逐条商量，扫一眼就行）
- [ ] ④ **写进看板**：默认**不带 `--to`**——`看板 handoff "<标题>" --detail "<六块全文>"`，落看板底下的「📋 交接单（AI 干完活留下的）」专区，谁都能接（2026-10-06 他拍板：交接单是交接单、AI 是 AI，默认不挂任何一家名下；实测挂 Claude 名下他找不到去哪接）
  - 标题两行内：哪摊活 + 下一步干啥，例：`酒馆出图接着调：3.5 已定档，接着调改 3.4；先问 3.5 设不设正在用`
  - 六块全文从 md 读进参数：bash 里写 `--detail "$(cat 那份.md)"`。详情里带英文双引号容易把命令拆坏，六块里引话用「」
  - **只有他点名「这条交给 XX」才加 `--to 那家`**，挂那家名下；专区就是看板最底下那一栏，单子要看得到才算写好
- [ ] ⑤ **看板没开**（命令报「看板没开」）：自己把桌宠开起来再写，不用问他——
  ```powershell
  $入口 = 'E:\个人AI资源管理\10_按项目存放（某个项目专用的脚本和资料）\01_手作园（自己从0搓的·应用网页工具）\应用\多Agent桌面宠物（统一通知与权限说明）\入口（开发版·跑源码）'
  Start-Process "$入口\多Agent桌面宠物.exe" -WorkingDirectory $入口 -RedirectStandardOutput "$env:TEMP\桌宠out.log" -RedirectStandardError "$env:TEMP\桌宠err.log"
  ```
  单实例，重复开不会多开。等十秒左右再跑 ④；还报没开就看那两份日志
- [ ] ⑥ **确认在看板上**：`看板 list --handoff` 能看到这条；告诉他「新开窗口说『接看板里的交接单』」

**算做完**：`list --handoff` 里有这条，详情六块齐全；他知道新窗口该说什么。

## 二、接交接单（新窗口开局）

- [ ] ① `看板 list --handoff --json`，默认接专区那条（assignee 待定/无的；他点名哪条就接哪条；好几条又没点名，列标题问他接哪条）
- [ ] ② 读那条的 `detail` 六块；按「接手要开、要关的」加载 skill、关该关的；按「项目」读它指的文件
- [ ] ③ **先问「等他回答的」**，他答了再动「我欠他的」里跟那些问题有关的事
- [ ] ④ `看板 remove <条目id>` 删掉这条（内容已经接到这个窗口了，留着会过时，下个窗口还会误接）
- [ ] ⑤ 从「我欠他的」第一条接着办

**算做完**：交接单从看板上删了；第一句话问的是「等他回答的」；没替他拍板。

## 三、坑清单

- **压缩已经不用了**（他 2026-10-04 定）：官方文档原话「`/compact` reads the conversation it summarizes, so compacting a large context is itself a large request」，换窗口只多带一张交接单。窗口快满了就写交接单，别建议他压缩
- **Claude Code 自己会自动压缩**：上下文满了它不问人就压。压完有钩子提醒先翻项目说明找回关键信息（E 盘钩子库 `压缩后-找回关键信息.ps1`），照着做，别凭摘要印象干
- **桌宠开着才连得上**：命令读 `%APPDATA%\AgentPetHub\bookmark\cli-port.json` 找端口，桌宠没开就报「看板没开」、退出码 1，不会卡住
- **详情只能当一个参数传**：命令没有「从文件读详情」的选项（待办：改 bookmark-cli.mjs 加一个，已记进看板 Claude 组）
