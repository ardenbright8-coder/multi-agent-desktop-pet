# 多 Agent 桌面宠物 · 应用现行设计

> 状态：询问面板和权限面板的方案已经敲定，程序代码还没有按新方案修改。

## 这个应用干什么

多 Agent 桌面宠物把 OpenCode、Claude Code、Pi、Hermes 的工作状态、询问、权限、完成和失败集中到一个桌面入口。用户离开终端后，也能看见哪个 Agent 正在做什么，并在需要时直接作出选择。

## 现行界面分块

1. **宠物状态**：幼苗动作、状态气泡、大小和活泼程度。
2. **询问面板**：显示 Agent 当前在问什么、简短说明和原来的选项。
3. **权限面板**：说明 Agent 想执行什么、为什么要权限、会动到哪里，再显示真实支持的权限选项。
4. **自己输入**：用户不选现成答案时，可以输入自己的做法、限制或命令。
5. **结果回传**：确认后把选择交回 Agent，并自动关闭面板；右上角和底部都能直接关闭。
6. **会话索引**：保留历史、搜索和连接状态，不和询问面板混在一起。

## 两种面板共用的结构

- 顶部只显示小号 Agent 名、面板类型和关闭按钮，不放会话编号，不写巨大的“需要你处理”。
- 标题直接说清楚当前正在处理的事情。
- 标题下面放一小段口语说明，把前因后果说完整。
- 下面显示 Agent 这一次真正给出的选项；选项数量和文字随任务变化，不写死成某几个答案。
- 最后一项始终允许用户自己输入。
- 选中后点“确认”，结果回传给 Agent，面板自动关闭。
- 如果某个 Agent 不支持直接回传权限，就明确写“回原窗口处理”，不能放一个点了没用的假按钮。

## 哪些是固定的，哪些会变化

固定的是面板结构、说话方法、关闭方式和结果回传方式。变化的是标题、说明、选项和风险：这一次可能是在放设计素材，下一次也可能是在改 class、配置代理、执行命令或修改文件。面板必须根据当前事件重新生成内容，不能套用固定文案。
