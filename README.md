# multi-agent-desktop-pet · 多 Agent 桌面宠物 + Agent 看板

Windows 桌面程序（Electron）：

- **桌宠**：盯着各家 AI 编程工具（Claude Code / Codex / Pi / Hermes / Grok / OpenCode），谁在干活、谁等你批准、谁干完了，一眼看见
- **Agent 看板**（`src/bookmark/`）：贴在屏幕右边的常驻看板，随手记、分组派活、AI 用命令领活、干完写报告等人审、图片标注、手机同步

手机端和设计记录在另一个仓库：[bookmark-tool](../../../bookmark-tool)

```
npm install
npm run build
npm run dev
```
