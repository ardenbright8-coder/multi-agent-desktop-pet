# 玻璃圆环小样

只用演示数据，不连接真实账号、不启动收件器，不改桌宠或自启。整夹不进入日常 dist。

- 启动小样 → 用项目已有 Electron 打开 `main.cjs`；桌面测试文件夹有快捷方式。
- 改显示 → `index.html`、`style.css`、`ui.js`。
- 改贴边和窗口 → `main.cjs`、`geometry.cjs`；界面只能通过 `preload.cjs` 调本小样。
- 验证交互 → `verify.mjs`（公共 Playwright 驱动，不移动物理鼠标）。
- 看图标 → `bubble.ico`，是本工具入口图标，不是脑图素材。

百分比统一指剩余，每个账号一环，中间显示余量最少账号；悬停展开，移开收回，右键可看详情。只有小球和卡片接鼠标，透明空白让开。

玻璃采用透明底、弧面高光和细边缘；网页滤镜不等于能折射 Windows 背后的其他应用。
