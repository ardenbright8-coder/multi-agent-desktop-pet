# 玻璃圆环小样

只用演示数据，不连接真实账号、不启动收件器，不改桌宠或自启。整夹不进入日常 dist。

- 启动小样 → 用项目已有 Electron 打开 `main.cjs`；桌面测试文件夹有快捷方式。
- 改显示 → `index.html`、`style.css`、`ui.js`。
- 改贴边和窗口 → `main.cjs`、`geometry.cjs`；界面只能通过 `preload.cjs` 调本小样。
- 改代码前看边界 → `AGENTS.md`；验边界用 `verify-boundaries.cjs`。
- 核对叫法 → `00_叫什么（本组件的叫法）.md`。
- 验证交互 → `verify.mjs`；验纯手势和几何用 `interaction.test.cjs`。
- 看图标 → `bubble.ico`，是本工具入口图标，不是脑图素材。

百分比统一指剩余，每个账号一环。平时25、碰上50，悬停不出面板；右键打开224×218详情。左右划切当前账号，数字纯白、对应环高亮；按住半秒再拖动位置。透明空白让开。

材质为用户指定的暗色磨砂；`native-glass.cjs` 处理Windows背景柔化，`interaction.js` 处理纯手势。四份设计Skill只下载读取，没有全局挂载。
