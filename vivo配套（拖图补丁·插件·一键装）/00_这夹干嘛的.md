# vivo配套（拖图补丁·插件·一键装）

桌宠 vivo 截图板块（`src\vivo\`）以外的代码：vivo 拖图补丁、Claude Code 和 Pi 的拖图插件正本、换电脑一键装和体检。不进桌宠程序。方案和坑看项目里的 `..\..\vivo截图（复制补图·拖图补丁·换电脑一键装）\`。

| 东西 | 干啥 |
|---|---|
| `换电脑一键装.ps1` | 一键装齐：vivo 补丁、Claude Code 插件和设置、Pi 插件，最后体检；装好的跳过，可反复跑 |
| `体检.ps1` | 一条条报每样在不在、对不对，只看不改 |
| `拖图补丁\` | 做补丁 `打补丁.cjs`、装补丁 `双击装补丁.cmd`、`退回原版.ps1`；大文件在 `D:\Downloads\vivo办公套件\拖图补丁备份\` |
| `Claude Code插件\` | 拖图提示插件正本 `vivo-drag-image\`，`接设置.cjs` 往设置文件里接插件和兜底钩子 |
| `Pi插件\` | `vivo-drag.ts` 正本：图片块 + 拖图提示 |

## 硬规矩

- 插件只改这里的正本，改完跑 `换电脑一键装.ps1` 拷到 C 盘
- 改了文件夹名要同步改 `src\vivo\drag-patch.ts` 的 `KIT_DIR_NAME`（测试会红）
